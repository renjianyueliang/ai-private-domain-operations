# SaaS 化服务器准备清单

当前项目已经升级为本地 SaaS 演示雏形：客户工作台 `/workspace` 和平台管理后台 `/admin` 已经分离，有行业模板、知识库、AI 内容工厂、视频适配、发布计划、私域会话、套餐授权、到期状态、功能开关、用量统计、渠道状态和 AI 指挥官流程。服务器准备好后，建议按下面顺序继续。

## 当前 SaaS 页面边界

- `/workspace`：客户使用端，只看自己的 AI 指挥官、任务流转、行业模板、知识库、内容任务、视频任务、发布计划、私域会话、套餐用量、漏斗和渠道。
- `/admin`：平台管理端，只给平台方使用，用于查看全部客户租户、行业模板、套餐、用量、内容任务、视频任务、渠道状态和 SaaS 化进度。
- 当前已有登录页、服务端会话、演示角色兼容、路由保护、服务端接口拦截、PostgreSQL 迁移/seed、对象存储状态、BullMQ 队列入口、连接器状态、账务记录和本地回退，但还没有真实账号注册/密码体系、企业 SSO、支付网关和生产级密钥管理。

## 第二版新增能力

- 行业模板库：交易教学、金融、医美、中医。
- 客户知识库：客户资料作为 AI 内容和回复依据。
- AI 内容工厂：自动生成选题、脚本、标题、封面文案、评论引导和私信话术。
- 视频工厂：展示视频切片、比例适配、字幕、时长、平台版本和风控检查。
- 发布中心：按平台区分官方 API、半自动、素材包和人工发布。
- 私域会话中心：评论/私信进入线索池，AI 生成回复建议，高风险转人工。
- 本地真实上传：知识库和视频文件可上传到 `.local-data/`。
- 本地任务队列：上传知识库会生成解析任务，上传视频会生成转码、字幕、合规审核任务。
- 任务执行入口：`/api/jobs/run` 可以推进队列；文本知识库做基础抽取预览，视频任务生成多平台处理清单。
- 模型网关：支持 OpenAI、OpenAI-compatible 备用端点和 mock 回退，并记录调用事件。
- 后台开通草稿：`/api/admin/tenants` 保存客户开通草稿。
- 权限演示：平台管理员、客户管理员、运营员工可以上传，只读观察员不能上传。
- 套餐授权：已定义试用版、基础版、增长版、企业版，支持到期、席位、额度和功能开关。
- 服务端拦截：知识库上传检查知识库功能和存储额度；视频上传检查视频工厂、视频任务额度和存储额度。
- 数据库结构：`db/schema.sql` 已覆盖服务器版核心表。
- 数据库迁移：`npm run db:migrate` 可执行 `db/schema.sql` 并记录 checksum。
- 数据初始化：`npm run db:seed` 可初始化套餐、功能开关和演示租户。
- 路由权限保护：`/admin`、`/workspace` 未登录会跳转 `/login`。
- Redis/BullMQ 入口：配置 `REDIS_URL` 后，上传任务可进入 `ai-saas-jobs` 队列，`npm run worker` 启动消费者。
- 对象存储入口：预留 S3/R2/OSS 兼容环境变量；当前未接具体 SDK 时仍本地镜像保存并显示待配置边界。
- 连接器状态中心：Telegram、企业微信、微信客服、YouTube、TikTok 按官方凭证判断；抖音、快手、小红书、视频号默认素材包/人工发布。
- 合同、发票、收款记录：平台管理员可创建账务记录，后续接支付、合同和发票服务商。

## 服务器第一阶段

- Node.js 运行环境
- PostgreSQL 数据库
- Redis 队列
- HTTPS 域名
- `OPENAI_API_KEY`
- 应用日志目录或日志服务
- 定时任务入口
- 对象存储，用于存放原始视频、剪辑结果、字幕文件和封面图
- 队列工作器，用于异步执行视频转码、字幕生成、平台发布任务
- 后台管理员登录
- 租户级权限校验中间件
- 套餐、订阅、功能开关和用量扣减逻辑

## 当前本地上传实现

- 文件保存位置：`.local-data/uploads/<tenantId>/<knowledge|video>/`
- 记录保存位置：`.local-data/records.json`
- 知识库上传后生成任务：`knowledge_ingest`
- 视频上传后生成任务：`video_transcode`、`subtitle_generation`、`compliance_review`
- 当前队列已可由 API 触发推进，但不会真的转码、识别字幕或调用平台 API。
- `.local-data/` 已加入 `.gitignore`，不要把客户资料提交到 Git。

## 服务器第二阶段：账号、权限与租户隔离

- 真实账号注册、登录、密码重置或企业 SSO
- 平台管理员角色
- 客户管理员角色
- 客户员工角色
- 客户审核员角色
- 用真实用户表替换当前 demo 用户
- 会话密钥使用生产密钥管理，不再使用开发默认值
- 套餐到期自动禁用写入能力
- 席位上限控制
- 功能开关服务端拦截
- 租户级 workspace 数据隔离
- 管理后台操作审计
- 客户端不能访问其他租户数据

## 服务器第三阶段：内容与视频流水线

- 知识库上传、解析、向量检索
- 原始视频上传
- 视频切片任务队列
- 字幕生成与校对
- 多尺寸导出：9:16、16:9、1:1
- 平台发布参数生成：标题、简介、标签、封面、发布时间
- 发布前合规审核与人工确认
- 发布结果回写：成功、失败、审核中、需重试

## 服务器第四阶段：平台连接器

优先接官方能力，不做个人号外挂或模拟点击。

- YouTube：客户 OAuth 授权后，使用官方上传能力；发布前保留审核按钮。
- TikTok：走官方 Content Posting 能力；需要客户账号授权和平台权限审核。
- Telegram：创建 Bot，使用 Webhook 接收用户主动咨询或群消息，再由会话中心回复。
- 企业微信：客户提供企业主体和应用配置，使用联系我、客户联系、消息回调、标签和员工分配。
- 微信客服/公众号/小程序客服：客户授权后接入官方客服消息和事件回调。
- 抖音、快手、小红书、视频号：根据开放平台实际权限决定是否自动发布；受限时生成素材包、标题、封面、正文、标签和人工发布清单。

所有连接器都必须写入：

- 授权账号
- 授权范围
- 回调地址
- token/secret 的加密存储位置
- 发布/回复频率限制
- 失败重试和人工接管规则

## SaaS 数据库核心表

- `tenants`：客户租户
- `users`：客户账号和角色
- `workspaces`：客户工作区
- `agents`：AI 员工配置
- `tasks`：任务队列
- `workflow_runs`：指挥官执行记录
- `knowledge_documents`：客户知识库文档
- `leads`：客户线索
- `messages`：话术草稿和审核记录
- `content_briefs`：AI 生成的选题、脚本、标题、封面文案
- `video_assets`：原始视频、切片、字幕、封面、导出文件
- `publish_jobs`：平台发布任务、授权状态、发布结果
- `conversations`：评论、私信、企微、Telegram 会话
- `industry_templates`：行业规则、禁用表达、免责声明、审核策略
- `plans`：套餐价格、席位、线索、AI 执行、视频任务和存储额度
- `plan_features`：套餐默认包含的功能
- `subscriptions`：套餐、授权、到期时间
- `tenant_feature_flags`：单个客户的功能开关覆盖
- `usage_records`：AI 调用、线索、存储、席位用量
- `audit_logs`：关键操作和合规审核日志

## 上线边界

第一版 SaaS 建议只开放：

- 客户登录
- 客户工作区
- 知识库上传
- 线索导入
- AI 指挥官执行
- 合规审核
- 人工确认
- 数据看板
- 内容工厂
- 视频工厂
- 发布计划
- 私域会话中心

暂不开放：

- 自动私聊
- 自动群发
- 自动拨打电话
- 自动收款
- 自动承诺成交
- 个人微信外挂
- 绕过平台授权的自动发布
- 绕过平台限制的批量私信或批量加好友

## 多行业合规边界

交易教学/金融必须持续禁止：

- 保证收益
- 喊单
- 跟单
- 荐股荐币
- 诱导高杠杆
- 暗示稳赚不赔
- 虚假盈利截图
- 把历史案例包装成未来收益

医美必须持续禁止：

- 永久有效
- 百分百变美
- 无风险
- 虚假前后对比
- 未授权案例
- 价格诱导和夸大疗效

中医必须持续禁止：

- 包治
- 根治
- 替代医院治疗
- 自动诊断
- 自动开方
- 无证诊疗

## 下一步开发顺序

1. 在服务器上配置 PostgreSQL、Redis、对象存储、域名、HTTPS、`SAAS_SESSION_SECRET` 和 `OPENAI_API_KEY`。
2. 运行 `npm run db:migrate`、`npm run db:seed`，再启动 `npm run worker`。
3. 把 demo 用户替换为真实账号体系，补注册、密码重置、企业 SSO、CSRF、速率限制和审计留存。
4. 接对象存储真实 SDK，把原始文件、导出视频、字幕和封面写入云桶。
5. 接知识库解析、切片、向量检索和引用来源展示。
6. 接 FFmpeg/云媒体服务，完成真实视频转码、字幕识别、封面生成和平台尺寸导出。
7. 接第一批官方连接器：Telegram Bot、企业微信、微信客服、YouTube。
8. TikTok、抖音、快手、小红书、视频号按开放平台权限逐步接；没有官方授权时只保留素材包和人工发布。
9. 接支付、发票、合同、用量扣费、续费、暂停和套餐升级。
10. 做安全扫描、备份策略、日志留存、失败重试和人工接管流程。
